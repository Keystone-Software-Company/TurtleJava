In order to install, use the link below to download all remaining files:

https://drive.google.com/file/d/1O0HoLxYA50z6NImfnpIGC9wXFn1bIQER/view?usp=drive_link

When downloaded, extract the .zip file into a regular folder. Place all the files in that folder and the ones from github into one main folder.

Make sure fabric is installed on your computer. If it is not installed already, use the fabric installer you got from the github page.

Use Minecraft 26.3 and the latest loader version available.

After that, you can use Turtle and begin modding.
